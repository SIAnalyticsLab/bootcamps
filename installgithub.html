Creating a GitHub Account & Installing GitHub Desktop

Beginner Step-by-Step Guide

Follow this from top to bottom. Do each action before moving to the next step.

PART 1: Create a GitHub Account

Step 1: Go to GitHub

  • Open your web browser (Chrome is fine).
  • Type: github.com
  • Click Sign up.

Step 2: Enter Your Details Carefully

You will be asked for:

  • Email address
  • Password
  • Username

Choose your username carefully. This is your professional identity on GitHub.

Good examples:

  • olugbenga-asaolu
  • gbenga-analytics
  • si-analytics-lab

Avoid:

  • Random numbers
  • Slang
  • Usernames you may regret later

Use an email address you can always access.

Step 3: Verify Your Email

  • Open your email inbox.
  • Look for a message from GitHub.
  • Click the verification link (or enter the code if prompted).

If you do not see the email:

  • Check Spam/Junk
  • Search for “GitHub”
You cannot fully use your account until this is completed.

Step 4 (Optional but Recommended): Enable Two-Factor Authentication

  • Click your profile picture (top right).
  • Go to Settings.
  • Find Password and authentication.
  • Enable Two-Factor Authentication (2FA).

This protects your account from unauthorized access.

PART 2: Download and Install GitHub Desktop

GitHub Desktop is an application that lets you use Git without typing commands.

Step 5: Download GitHub Desktop

  • Open a new browser tab.
  • Go to: desktop.github.com
  • Click Download for Windows or Download for macOS.

Only download from the official website.

Step 6: Install on Windows

  • Open your Downloads folder.
  • Double-click the downloaded .exe file.
  • Follow the installation prompts.
  • The app will open automatically after installation.

Step 7: Install on macOS

  • Open your Downloads folder.
  • Double-click the .zip file to unzip.
  • Open GitHub Desktop.

PART 3: Connect GitHub Desktop to Your GitHub Account

Step 8: Sign in From GitHub Desktop

  • Open GitHub Desktop.
  • Click Sign in to GitHub.com.
  • Your browser will open automatically.

Step 9: Authorize GitHub Desktop

  • In your browser, log in (if asked).
  • Click Authorize GitHub Desktop.
  • Return to GitHub Desktop.

You should now see that you are signed in.

Step 10: Set Your Commit Name and Email

  • Name
  • Email

Use your real name and the same email you used to create your GitHub account.

PART 4: Quick Test (Highly Recommended)

Step 11: Create a Practice Repository

  • Click File → New repository
  • Repository name: si-analytics-practice
  • Choose a folder location (example: Documents/SI-Analytics)
  • Check Initialize with README
  • Click Create repository

Step 12: Publish to GitHub

  • Click Publish repository
  • Choose Public or Private
  • Click Publish

Confirm the repository appears on your GitHub profile.

Step 13: Make One Small Change and Push

  • Open README.md
  • Add a new line: Setup complete ✅
  • Save the file
  • Commit and Push

Common Beginner Issues

Problem: No verification email

  • Check Spam/Junk
  • Search inbox for “GitHub”
  • Resend verification from account settings

Problem: Desktop login not connecting

  • Make sure you clicked Authorize GitHub Desktop
  • Close Desktop and reopen it
  • Try signing in again from Desktop settings

Problem: Wrong name or email in commits

  • Open GitHub Desktop settings
  • Go to the Git section
  • Update your name and email

Final Outcome Checklist

  • Verified GitHub account
  • GitHub Desktop installed
  • Desktop connected to GitHub
  • Published test repository
  • Successfully pushed a commit

If all five are complete, you are fully ready for bootcamp workflows, cloning repositories, and submitting assignments.
