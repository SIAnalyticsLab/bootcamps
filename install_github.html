Beginner Step-by-Step Guide

Follow this page once, from top to bottom. No prior Git knowledge required. Read each step, do the action, then move to the next. If you get stuck, jump to Troubleshooting.

What you’re setting up

GitHub (online) + GitHub Desktop (on your laptop) so you can save and publish your projects.

What you’ll do

Create account, verify email, install Desktop, sign in, configure your name/email, run a quick test.

How to use this page

Each step is collapsible. Open one, complete it, then close it and move forward.

Before you start

Quick setup essentials so you don’t get interrupted mid-way.

0

Have these ready

Email address you can access, a strong password, and your laptop (Windows or macOS).
  • Email: you must open the verification message later.
  • Password: use something strong and unique (do not reuse old passwords).
  • Internet: stable connection helps when Desktop opens a browser to authorize your login.
Tip: Create a simple folder on your laptop now, for example Documents/SI-Analytics. You will save repositories there later.

Create a GitHub account

GitHub is your online home for projects, code, and portfolios. You will create a personal account and verify your email.

1

Go to GitHub and start sign-up

Open your browser and begin the GitHub registration flow.
  1. Open a browser (Chrome is fine).
  2. Visit github.com.
  3. Click Sign up (or use the sign-up box on the homepage).
If you already have an account, skip to Install GitHub Desktop.
2

Enter your details carefully

Email, password, and a username you can keep long-term (portfolio-friendly).

Choose a username you can confidently share on your CV and LinkedIn.

  • Good: olugbenga-asaolu, gbenga-asaolu, si-analytics-lab
  • Avoid: random numbers, slang, or names you may outgrow.
Important: Use an email address you can always access. If you lose access, account recovery becomes harder.
3

Verify your email

You will receive a verification message. Confirm it before moving on.
  1. Open your email inbox.
  2. Find GitHub’s verification email.
  3. Click the verification link or enter the code (depending on what GitHub shows you).
If you cannot find it, check Spam/Junk or search your inbox for “GitHub”.
4

Optional: Turn on two-factor authentication (recommended)

This adds a second layer of security to protect your account.

GitHub’s onboarding guidance recommends verifying your email and configuring account security early.

  • In GitHub, open Settings.
  • Find Password and authentication.
  • Enable Two-factor authentication (2FA) using an authenticator app.
If you are overwhelmed, you can skip 2FA for now. Come back later once your account is working smoothly.

Install GitHub Desktop

GitHub Desktop is an app that helps you work with repositories without using the command line.

5

Download GitHub Desktop

Use the official download page to avoid unsafe installers.
  1. Open a new browser tab.
  2. Go to desktop.github.com.
  3. Download the version for your operating system (Windows or macOS).
GitHub’s Desktop docs provide platform-specific installation steps and supported OS requirements. Keep your system updated.
6

Install on Windows

Run the installer and follow prompts.
  1. Open your Downloads folder.
  2. Double-click the GitHub Desktop installer (.exe).
  3. Follow the prompts until the app opens.
If Windows shows a security prompt, confirm the app is “GitHub Desktop” from the official source.
7

Install on macOS

Unzip the file, then open the app.
  1. Open your Downloads folder.
  2. Double-click the GitHub Desktop .zip to unzip it.
  3. Open the GitHub Desktop app.
If macOS blocks the app, open System Settings → Privacy & Security, then allow the app.

Connect GitHub Desktop to your GitHub account

This is the most important part. Desktop will open a browser so you can authorize your login securely.

8

Sign in from GitHub Desktop

Use “Sign in to GitHub.com” inside the app.
  1. Open GitHub Desktop.
  2. Click Sign in to GitHub.com.
  3. Your browser will open a GitHub page asking you to authorize Desktop.
This authentication flow is part of GitHub’s recommended Desktop setup process.
9

Authorize GitHub Desktop in the browser

Approve the authorization so Desktop can access your repositories.
  1. In the browser, sign in (if asked).
  2. Click Authorize GitHub Desktop.
  3. Return to GitHub Desktop. It should now show you as signed in.
If you enabled 2FA, GitHub may request a code. Use your authenticator app and continue.
10

Set your commit name and email

This identifies you as the author of changes you publish.

GitHub Desktop will ask for a Name and Email. Use:

  • Name: your real name (example: Olugbenga Asaolu)
  • Email: the email linked to your GitHub account
If you use multiple emails, choose the one you want associated with your public contributions.

Quick test (recommended)

Create a tiny practice repository to confirm everything works end-to-end.

11

Create a practice repository

Do this inside GitHub Desktop so you can publish it to GitHub.
  1. In GitHub Desktop, click File → New repository…
  2. Name it: si-analytics-practice
  3. Choose a local path (example: Documents/SI-Analytics)
  4. Check Initialize this repository with a README
  5. Click Create repository
A README is a simple text file that explains what your project is. Most public repos have one.
12

Publish it to GitHub

This confirms your Desktop-to-GitHub connection works.
  1. In GitHub Desktop, click Publish repository.
  2. Leave the name as-is, decide if it should be private or public.
  3. Click Publish.
  4. Open your browser and confirm the repository appears in your GitHub profile.
If “Publish repository” is missing, confirm you are signed in (top right profile area in Desktop).
13

Make one small change and push

This confirms commit and push works.
  1. Click Repository → Show in Explorer/Finder.
  2. Open README.md with any text editor.
  3. Add a new line: Setup complete ✅, then save.
  4. Return to GitHub Desktop, you should see the change.
  5. Write a commit message: Update README.
  6. Click Commit to main.
  7. Click Push origin.

Troubleshooting

Common first-timer issues and quick fixes.

A

I did not receive the GitHub verification email

Most issues are inbox filters or typos.
  • Check Spam/Junk folders.
  • Search your inbox for “GitHub”.
  • Confirm your email address was typed correctly in GitHub settings.
  • Resend the verification email from GitHub account settings.
B

Desktop login opens the browser, but it does not connect

Usually a blocked popup, wrong browser session, or incomplete authorization.
  1. Try again in Desktop: File → Options/Preferences → Accounts.
  2. Ensure you clicked Authorize GitHub Desktop in the browser.
  3. Close Desktop and reopen it, then retry sign-in.
  4. If you use multiple browsers, keep the authorization in the same browser that opened automatically.
C

My commits show the wrong name or email

Fix it once in Desktop settings.
  1. Open GitHub Desktop settings: File → Options (Windows) or GitHub Desktop → Settings (macOS).
  2. Go to Git.
  3. Set your correct Name and Email.
Your name/email identifies authorship of commits, so keep it consistent for your portfolio.
